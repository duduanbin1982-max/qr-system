# 生产排程 Task 1：生产节点与工作日历预检固化

**执行日期：** 2026-09-22（Asia/Shanghai）
**范围：** 本地代码分支的只读预检能力和回归测试
**生产安全边界：** 未连接、未写入、未迁移、未停服、未重启 `192.168.1.8`

## 1. 本阶段目标

把“生产节点主数据”和“工作日历容量”变成自动排程发布前的明确检查项，避免只看到节点数量，却没有确认节点是否有有效日历或每日有效生产分钟。

## 2. 已完成改造

`scripts/production_node_operations.py` 的只读 `preflight` 新增以下检查：

- 活动生产节点按工序统计；
- 与目标节点分布比较：下料 1、铆接 4、焊接 10、抛丸 1、打磨 1、镗孔 2、喷漆 2；
- 报告缺失节点和额外节点，不删除、不自动停用；
- 检查每个活动节点是否引用活动工作日历；
- 检查工作日历是否至少存在一个有效班次；
- 按班次分钟数计算每日有效容量；
- 检查有效容量是否为已确认的 540 分钟；
- 将异常节点和日历信息写入预检结果，供审批和部署证据使用。

额外节点不会被静默视为错误，而是单独记录为 `extra_node_distribution`，后续必须通过业务确认和受控停用处理。无效日历会使预检结论失败，阻止进入正式发布门槛。

## 3. 测试结果

本阶段新增并验证：

- 现有节点映射、V091 迁移、节点排程、影子排程、容量、交期风险和动态重排回归保持通过。
