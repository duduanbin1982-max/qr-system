# 生产节点排程 Task 12 运行手册

本文档定义生产节点排程从旧产线事实切换到稳定生产节点事实时的只读预检、
副本演练、影子运行、功能开关和回退证据链。每个阶段都是独立授权边界；
没有新的授权，不得自动进入下一阶段。

## 证据目录和保留规则

所有命令使用同一部署幂等键和目标提交 SHA。证据目录至少保留：

- 数据库最终备份及 `database_fingerprint`；
- 附件、前端发布包和各自校验摘要；
- V086–V090 迁移日志及迁移后的 `PRAGMA user_version`；
- `preflight`、`compat-audit`、`shadow-run`、`acceptance` 和
  `rollback-readiness` JSON；
- 兼容审计的全部历史观察记录，不删除旧差异；
- 停服、启动、健康检查和回退日志。

原生产数据、附件、备份、迁移日志和审计证据必须保留。任何失败先恢复本次
已验证的数据库/附件/前端备份，再回退代码；不得用回退覆盖或删除证据。

## 阶段 1：代码和 V086–V090 迁移（全部开关关闭）

1. 在生产库副本运行：
   `python scripts/production_node_operations.py preflight ...`。
2. 运行 `migrate-replica`，只对副本执行待迁移计划；确认源库摘要未变化。
3. 核对 21 条旧产线均已唯一映射到生产节点，并报告额外的节点专属能力；
   生产节点总数允许随实际能力扩展，不得继续硬编码为恰好 21 个。同时核对
   历史事实缺失数、外键和完整性检查。
   状态为 `blocked` 且从未分配旧产线的修订项必须保持未分配，记录
   `intentionally_unassigned_blocked` 审计证据；不得为消除差异而伪造生产节点。
4. 生产维护窗口内完成最终数据库、附件和前端备份，校验 manifest 后再停服。
5. 停止 `qr-system.service`，执行迁移，保持以下值为 `false`：
   `PRODUCTION_NODE_QUERY_ENABLED`、`PRODUCTION_NODE_COMPAT_AUDIT_ENABLED`、
   `PRODUCTION_NODE_WRITE_ENABLED`、`PRODUCTION_NODE_ENGINE_ENABLED`、
   `LEGACY_PROCESS_LINE_WRITE_BLOCKED`。
6. 重启服务并执行健康、数据库连接和迁移版本验收。任一失败按部署 manifest
   恢复备份和回退提交。

## 阶段 2：查询和兼容审计观察

在单独授权后，用 `set-flags --state query_audit` 原子更新环境文件。该命令
保留无关变量、禁止跳级，并生成不可覆盖的 `set-flags-<幂等键>.json`。

验收要求：服务健康；节点查询可用；每个 `(scope, source_id)` 只取最新
观察值；最新 `mismatch` 必须为零。历史 mismatch 记录仅归档，不删除。

## 阶段 3：节点写入和影子运行

单独授权后切换到 `write_shadow`。先运行 `shadow-run`，确认：

- 独占节点没有重叠时间段；
- 每个排程数量等于其分段数量总和；
- 序列号没有跨多个生产节点拆分。

此阶段只写入节点事实和影子证据，不把节点结果投影为生产执行结果；旧产线
写入仍保持开启。

V090 将影子结果写入独立的 `production_node_shadow_*` 不可变台账。影子计算
虽然复用节点排程算法，但在数据库保存点内回滚正式排程、排程运行、排程版本
和订单摘要的全部临时变化；只有隔离校验通过后才允许提交影子台账事实。

## 阶段 4：节点排程引擎

单独授权后切换到 `engine`。执行 `acceptance`，除阶段 3 条件外，验证排程
版本、锁定、审批和生产节点日历快照。任何冲突、数量不守恒或兼容差异都阻断
切换。可通过同幂等键安全重放已完成的开关操作。

## 阶段 5：阻断 Legacy 产线写入

只有在节点引擎稳定观察并再次批准后，才能切换到 `legacy_blocked`。该阶段
不得跳过前四阶段；旧查询兼容仍由查询开关控制，Legacy 写路径阻断必须有
独立验收记录。

## 回退

回退前必须先运行 `rollback-readiness`，生成包含当前部署提交、目标回退提交、
数据库摘要和幂等键的证据。`set-flags` 的任何后退操作都必须引用该证据；
没有有效证据时命令拒绝执行。回退顺序为：停服、恢复数据库/附件/前端备份、
切换回退提交、恢复原开关、启动服务、健康检查并保存全部日志。

## 命令输出约定

所有 CLI 命令 stdout 只输出一个 JSON 对象，包含 `ok`、`mode`、`checks`、
`counts`、`digests` 和 `artifacts`。阻断或参数错误返回退出码 `2`；命令失败
不会把半成品证据当作成功证据。
