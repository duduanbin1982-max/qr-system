- 一次性工作副本试排前后的 `order_processes` 进度指纹一致。
- 一次性工作副本试排前后的 `work_records` 指纹一致。
- 工作副本会生成用于共享容量验收的候选排程事实；这些事实没有写回生产，也不是生产正式排程发布。

## 发现与后续

本阶段不阻断 Task 3，但试排发现 18 个订单存在交期风险，最大延期 30,925 分钟，最晚计划完成时间为 2026-11-03 10:55。该结果应在后续“冲突检测与交期风险预警”阶段进入业务分析，不能通过修改本次验收口径隐藏。

第一次本地尝试曾错误继承关闭的节点引擎开关，实际走了 Legacy 产线算法，因此出现“有分段、无节点分配”的 385 条假性数量违规；该结果已废弃。验收脚本现已明确固定在一次性副本中启用生产节点引擎，避免环境开关导致错误验收。第一次非一致性文件复制还出现无关索引校验异常，亦已废弃并改用只读 `serialize()` 一致性副本。
