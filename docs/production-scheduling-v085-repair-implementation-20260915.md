2. 工时标准精确绑定：
   - 创建/编辑支持显式 `route_version_id` + `process_version_id`。
   - 校验路线版本属于路线根、工序版本属于工序，且路线版本确实包含该工序版本。
   - 历史标准不会因编辑操作自动改绑当前路线版本。
   - 工时列表和路线分组按路线版本、工序版本展示。

3. 受控历史修复工具：
   - `scripts/repair_schedule_standard_bindings.py`
   - 固定处理三条历史路线的 19 条明确映射。
   - 只允许精确源标准复制；相同目标幂等跳过；有效期重叠且值不同直接阻断。
   - 不按相似度猜测、不修改源标准、不恢复路线根级 fallback。

4. 排程器：
   - 外协/非排程工序不查内部工时、不找产线、不置 `blocked`、不占用内部分钟。
   - 内部工序继续严格按路线版本、工序版本和产品范围匹配工时。
