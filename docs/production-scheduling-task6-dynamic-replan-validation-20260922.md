2. 统一动态重排输入快照，纳入：

   - 报废记录；
   - 待处理与已完成返工记录；
   - 生产节点停机事件；

3. 实际生产事实变化自动标记待重排：
   - 普通报工批准；
   - 报废登记；
   - 新增返工；
   - 返工完成；
   - 新增停机；
   - 取消停机。
4. 动态重排规则：
   - 已完成工序冻结；
   - 部分完工仅重排剩余数量；
   - 待返工数量追加到剩余任务；
   - 报废不冒充合格完工数；
   - 已锁定任务保留节点和时间；
   - 锁定任务与停机、日历或前序冲突时明确阻断；
   - 新结果只形成 `draft` 修订版，不替换正式排程；
   - 待重排标记在草稿生成后仍保留，只有正式发布才清除。
5. 重排差异证据覆盖：
   - 生产节点变化；
   - 计划开始、结束时间变化；
   - 占用分钟变化；
   - 排程数量变化；
   - 完工、返工和剩余量快照；
   - 重排前后风险等级和延期分钟；
   - 风险改善、恶化或不变结论。
6. 重排后重新执行 Task 5 冲突检测和交期风险评估，提交、批准、发布门禁继续生效。
7. 生产排程 UI 新增：
   - 所选订单的“为什么需要重排”提示；
   - 重排草稿不会自动生效的明确警示；
   - 变化工序数、换节点数和风险变化；
