# 库存原生 CSV 导出设计

## 目标

为库存管理的“按订单”和“按产品编码”列表增加原生 CSV 下载，同时保留现有 XLSX 导出；两种格式必须使用相同的筛选、排序、分页绕过和权限口径。

## 方案

- 新增 `/api/inventory/export.csv` 和 `/api/inventory/product-groups/export.csv` 两个下载接口。
- 现有 XLSX 路由不变，避免影响当前前端和既有调用方。
- CSV 使用 UTF-8 BOM，保证 Excel 打开中文不乱码。
- CSV 使用标准 `csv.writer` 转义逗号、双引号和换行；不手工拼接行。
- 产品编码按字符串写入，并对危险前缀进行文本保护，避免 Excel 公式注入，同时保留前导零。
- 导出不采用页面分页，服务端循环读取全部匹配结果；筛选、排序、选中项和权限与 XLSX 一致。
- 下载继续要求 `inventory:export` 权限，并写入现有安全审计事件。
- 本轮不增加产品详情和库存流水 CSV。

## 验收

- 两个接口返回 `text/csv; charset=utf-8`，文件名以 `.csv` 结束。
- 过滤、排序、全部行数、数量汇总与列表一致。
- 205 条产品、前导零编码、逗号/引号/换行、中文和 Excel 公式前缀均有真实 API 测试。
- 无导出权限返回 403；导出不修改库存事实。
- 现有 XLSX、前端构建和库存回归测试保持通过。
